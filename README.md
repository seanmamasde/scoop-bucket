My [Scoop](https://scoop.sh) bucket.

```pwsh
scoop bucket add seanmamasde https://github.com/seanmamasde/scoop-bucket
scoop install seanmamasde/winpager
```

| App | Description |
|---|---|
| [winpager](bucket/winpager.json) | [WinPager](https://github.com/seanmamasde/WinPager): KDE Plasma-style virtual desktop pager for the Windows 11 taskbar |

Excavator checks for new upstream releases every 4 hours and updates the manifests.
